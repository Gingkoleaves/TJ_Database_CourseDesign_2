# 消耗性资产管理系统 - 用户手册

## 1. 系统概述

消耗性资产管理系统是一个专门用于管理实验室或机构消耗性资产的Web应用程序。系统支持资产入库、出库、库存查询、有效期预警和权限管理等功能。

## 2. 登录系统

### 2.1 访问系统
- 打开浏览器，访问系统URL（默认：http://localhost:3001）
- 在登录页面输入用户名和密码
- 点击"登录"按钮

### 2.2 登录问题解决
- 确认用户名和密码正确
- 检查大小写是否正确
- 如果忘记密码，请联系系统管理员

## 3. 主要功能模块

### 3.1 仪表板
- 显示系统关键指标
- 展示即将过期的资产
- 提供快速操作入口

### 3.2 资产定义管理
**功能**: 管理系统中的资产类型

**添加新资产**:
1. 点击"资产定义"菜单
2. 填写资产信息（名称、分类、品牌、型号、单位等）
3. 点击"添加资产"

**编辑资产**:
1. 在资产列表中点击"编辑"按钮
2. 修改资产信息
3. 系统自动保存更改

**删除资产**:
1. 在资产列表中点击"删除"按钮
2. 确认删除操作

### 3.3 分类管理
**功能**: 管理资产分类

**添加分类**:
1. 点击"分类管理"菜单
2. 输入分类名称
3. 点击"添加分类"

**编辑和删除分类**:
- 操作方法与资产管理类似

### 3.4 位置管理
**功能**: 管理资产存放位置

**添加位置**:
1. 点击"位置管理"菜单
2. 输入房间号、柜子号、货架号
3. 点击"添加位置"

### 3.5 库存管理
**功能**: 执行入库、出库、转移操作

#### 3.5.1 入库操作
1. 点击"库存管理"菜单
2. 选择"入库操作"标签页
3. 选择资产类型和存放位置
4. 输入数量、过期日期、来源等信息
5. 点击"执行入库"

#### 3.5.2 出库操作
1. 选择"出库操作"标签页
2. 选择库存批次
3. 输入出库数量和去向
4. 点击"执行出库"

#### 3.5.3 转移操作
1. 选择"转移操作"标签页
2. 选择库存批次和新位置
3. 输入转移数量
4. 点击"执行转移"

## 4. 系统功能

### 4.1 库存查询
- **库存总览**: 显示所有资产的总库存数量
- **即将过期**: 显示所有即将过期(30天内)的资产
- **位置明细**: 按位置查看资产分布

### 4.2 有效期管理
- 系统自动跟踪资产有效期
- 在仪表板显示即将过期的资产
- 支持按有效期筛选资产

### 4.3 权限管理
- 根据用户角色控制访问权限
- 某些角色只能管理特定分类的资产

## 5. 使用技巧

### 5.1 搜索和筛选
- 使用浏览器的搜索功能(Ctrl+F)快速查找
- 定期刷新页面获取最新数据

### 5.2 数据备份
- 系统数据由管理员定期备份
- 重要操作前建议记录相关数据

### 5.3 问题处理
- 遇到系统问题时，刷新页面重试
- 如问题持续，请联系技术支持

## 6. 常见问题

### 6.1 无法登录
- 检查用户名和密码是否正确
- 确认网络连接正常
- 联系系统管理员

### 6.2 数据加载缓慢
- 检查网络连接
- 清除浏览器缓存
- 联系系统管理员检查服务器状态

### 6.3 操作失败
- 检查必填字段是否完整
- 确认权限是否足够
- 尝试重新登录
