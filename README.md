# 消耗性资产管理系统

## 项目概述
本系统是一个完整的消耗性资产管理系统，用于管理实验室或其他机构的消耗性资产，包括入库、出库、库存管理、有效期预警和权限控制等功能。

## 系统架构
- 后端：Node.js + Express + MySQL
- 前端：原生JavaScript + HTML + CSS
- 数据库：MySQL

## 主要功能
1. 资产定义管理
2. 分类管理
3. 位置管理
4. 库存管理（入库、出库、转移）
5. 有效期预警
6. 权限管理
7. 数据统计和查询

## 数据库设计
- 维度表：资产定义、分类、位置
- 事实表：库存批次、入库记录、出库记录
- 系统表：用户、角色、权限

## 安装和运行
1. 安装MySQL数据库
2. 创建数据库并运行schema.sql脚本
3. 安装后端依赖: `npm install` 
4. 配置环境变量（数据库连接信息）
5. 启动后端服务: `npm start`
6. 启动前端服务: `npx live-server ./public --port=3001` (在frontend目录)

## API端点
- `/api/auth` - 认证相关
- `/api/assets` - 资产定义管理
- `/api/categories` - 分类管理
- `/api/locations` - 位置管理
- `/api/inventory` - 库存管理
- `/api/permissions` - 权限管理
